How the spreadsheet and the website stay in step

  1. Edit config/site-config.xlsx in Excel, Numbers or Google Sheets and save it as .xlsx.
  2. Drop it above and press Apply to site. The change is live in this browser straight away.
  3. Go to Save & publish, download site-config.js, and replace the file in assets/js/ in your repository so every visitor gets it too.

Save & publish

Two different things: Save keeps your work in this browser so you can see it by refreshing the site. Publish puts it on GitHub so everyone else sees it too.

1  Saved in this browser

Your edits are stored on this device. Refresh any page of the site and they are there. Nobody else can see them yet.

—

2  Publish to your live website

Download the two files below and commit them to your GitHub repository, replacing the existing versions. GitHub Pages rebuilds in about a minute.

FileGoes inContains
site-config.js assets/js/ Business details, colours, fonts, social links
content-overrides.js assets/js/ Your text edits and uploaded images
One-time step for content overrides. After adding content-overrides.js to assets/js/, add this line to every page just below the content.js script tag — or ask your developer to run python3 tools/apply_overrides.py, which does it for you:
<script src="assets/js/content-overrides.js"></script>

Start over

Removes every edit stored in this browser and puts the site back to how it was delivered. Your published files are not touched.

How to use this editor

Five minutes of reading that will save you a lot of guessing.

The short version

  1. Pick a section on the left.
  2. Change what you want.
  3. Press Save changes at the top right.
  4. Open the site and refresh — your change is there.
  5. When you are happy, go to Save & publish to put it live for everyone.

Replacing a photograph

Open Images & video, find the picture, press Upload and choose a file from your computer. Use a photo at least 1200 pixels wide; it is resized automatically. Press Revert to go back to the original at any time.

Things worth knowing

  • Edits live in this browser on this device until you publish. Clearing your browser data will remove them — take a backup first.
  • Browsers cap local storage at roughly 5 MB. The meter on the Save & publish tab shows how much you have used.
  • Text fields accept simple HTML. <span class="hl">word</span> gives you the cream highlight used in the headings.
  • Visitors can pick their own colour theme with the paint button on the site. That is their choice only and never changes what you set here.
